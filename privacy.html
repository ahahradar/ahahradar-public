이 방침은 앱스토어용 아아레이더 iOS 앱에 적용됩니다.

기기에서 처리하는 정보

현재 위치는 사용자가 ‘내 위치’를 눌러 권한을 허용했을 때 주변 지점과 거리를 계산하는 데 사용합니다. 앱 운영자의 서버로 위치를 전송하거나 위치 이력을 저장하지 않습니다. 검색어와 저장한 지점은 기기에서 처리하며 계정 가입을 요구하지 않습니다.

외부 서비스 연결

지도는 Apple MapKit을 사용하며 지도 표시 과정에 Apple의 개인정보 처리방침이 적용됩니다. 지점 데이터 갱신에는 GitHub Pages를 사용하며, GitHub Pages는 보안 목적으로 접속자의 IP 주소를 기록·보관합니다. 이는 파일 제공 서비스의 보안 접속 기록이며, 아아레이더는 이를 이용한 광고·사용자 추적을 하지 않습니다. 보관 방식은 GitHub 개인정보처리방침을 따릅니다. 갱신 요청에는 위치·검색어·즐겨찾기·사용자 식별자를 포함하지 않습니다.

‘네이버 지도’ 링크를 열면 네이버 서비스로 이동하며 지점 검색어가 전달됩니다. 해당 서비스의 개인정보 처리방침이 적용됩니다.

수집 및 추적

아아레이더 iOS 앱은 자체 사용 분석, 광고 식별자, 계정 정보 또는 사용자 추적을 사용하지 않습니다. 지점 저장 기능은 기기 내에 보관되며 앱 삭제 시 제거됩니다.
