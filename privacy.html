아아레이더지원개인정보

iOS 앱 개인정보처리방침

출시 준비 중인 아아레이더 iOS 버전 · 2026년 10월 26일 작성

이 페이지는 출시 준비 중인 앱스토어용 아아레이더 iOS 앱의 처리 방식을 안내합니다. 토스 미니앱과는 별도이며, 아직 일반 배포되지 않았습니다. 아아레이더는 로그인 없이 주변 커피 지점을 찾는 앱입니다.

위치·검색·저장한 지점

현재 위치는 사용자가 ‘내 위치’를 눌러 권한을 허용했을 때 주변 지점과 거리를 계산하는 데 사용합니다. 아아레이더 운영자의 서버로 현재 위치를 보내거나 위치 이력을 보관하지 않습니다. 검색어와 저장한 지점은 기기에서 처리합니다.

지도는 카카오맵 SDK를 사용합니다. 화면에 보여줄 지역의 지도 데이터를 카카오 서버에 요청하며, 현재 위치 주변을 표시하면 그 주변 지역에 대한 지도 요청이 발생합니다. 따라서 운영자에게 위치를 보내지 않는 것과 지도 제공자에게 네트워크 요청이 발생하는 것은 구분됩니다.

카카오맵과 외부 서비스

카카오맵 SDK는 앱 인증과 지도 표시를 위해 카카오 서버와 통신합니다. 서비스 인증용 앱 정보와 IP 주소 등 연결에 필요한 정보가 요청 과정에서 처리됩니다. SDK가 제공한 개인정보 보호 선언에는 앱 기능 제공을 위한 ‘기타 데이터’, 사용자와 연결되는 데이터, 추적에 사용하지 않음이 명시되어 있습니다. 세부 처리 기준과 문의 방법은 카카오 개인정보처리방침을 참고해 주세요.

지점 데이터 파일과 이 지원 사이트는 GitHub Pages를 사용합니다. GitHub Pages는 보안 목적으로 접속자의 IP 주소를 기록·보관합니다. 지점 파일 갱신 요청에는 현재 위치·검색어·저장한 지점·사용자 식별자를 넣지 않습니다. 보관 방식은 GitHub 개인정보처리방침을 따릅니다.

‘네이버 지도’ 같은 외부 지도 링크를 열면 선택한 지점의 검색어가 해당 서비스에 전달됩니다. 이후 해당 서비스의 개인정보 처리방침이 적용됩니다.

기기에 보관하는 진단 기록

문제 원인을 확인할 수 있도록 앱 동작의 성공·실패, 처리 시간·건수·숫자 오류 코드와 앱·OS·지점 데이터 버전, 시각, 임의의 세션 번호를 기기에 기록합니다. 기록은 기본으로 켜져 있으며, 진단 화면에서 끄거나 삭제할 수 있습니다. 자체 분석 서버로 자동 전송하지 않습니다.

진단 기록에는 현재 위치, 검색어, URL, 인증 키, 오류 메시지 원문, 이름·연락처·기기 고유 식별자를 넣지 않습니다. 최대 7일 또는 2,000건, 파일 1MiB 범위로 보관하며 다음 기록·조회 때 기간이 지난 내용을 정리합니다. 기록을 끄면 새로운 기록을 남기지 않고, 삭제하면 기존 기록과 앱 안의 공유용 파일을 지웁니다.

사용자가 선택하는 피드백·진단 공유

문제 제보 시 사용자가 작성한 메모, 선택한 지점의 식별번호, 앱·OS·데이터 버전을 공유용 파일에 넣을 수 있습니다. 진단 기록 포함 여부를 선택하고 내용을 확인한 뒤 iOS 공유 화면에서 직접 전송해야 합니다. 메모와 지점 식별번호는 일상 진단 기록에 자동으로 추가되지 않습니다. 작성 중인 메모는 기기에 초안으로 남으며, ‘작성 내용 비우기’ 또는 앱 삭제로 지울 수 있습니다. 진단 기록 삭제와 메모 초안 삭제는 별개입니다.

공유 화면을 여는 것만으로 운영자에게 전송되지 않습니다. 파일에 저장하면 사용자가 보관하고, 이메일 등으로 운영자에게 보내면 보내신 메모·진단 파일과 발신 이메일 주소를 문제 확인과 답변 목적으로 처리합니다. 다른 수신자나 서비스를 선택하면 그 수신자에게 전달되며 해당 서비스의 처리방침이 적용됩니다. 진단 기록을 제외하면 이벤트와 세션 식별자를 넣지 않고 작성한 메모·선택한 지점과 버전 정보만 공유할 수 있습니다. 민감한 개인정보는 메모에 적지 않아도 됩니다.

앱의 공유용 임시파일은 최대 3개를 유지하고 24시간이 지난 파일은 다음 접근 시 정리합니다. 사용자가 다른 앱이나 파일 앱으로 보낸 사본은 해당 앱에서 관리해야 합니다. 운영자가 받은 문의 내용은 문제 해결에 필요한 기간 동안 사용하고, 불필요해지면 삭제합니다. 법령상 보관 의무가 있으면 그 기간을 따릅니다.

광고·추적

아아레이더는 광고 식별자, 광고 추적, 사용자별 광고나 자동 사용 분석 서버를 사용하지 않습니다. 기기 내 진단 기록과 사용자가 보낸 문의를 광고 목적으로 이용하지 않습니다.

선택권과 문의
